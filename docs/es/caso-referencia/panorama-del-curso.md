# Digital Innovation Studio · Caso de referencia

Este curso de posgrado sanitizado reúne aproximadamente a 45 estudiantes de programas de data science, sistemas de información y gestión. Los equipos diagnostican una oportunidad real de transformación digital y diseñan, prototipan, validan y defienden una solución responsable basada en datos o IA.

El curso busca desarrollar encuadre de problemas, decisiones basadas en evidencia, colaboración interdisciplinaria, prototipado iterativo, uso responsable de IA, gobernanza y capacidad para defender decisiones relevantes.

El diseño actual en Canvas concentra la evaluación en el dossier final, el prototipo y el Demo Day. El equipo docente quiere conservar el proyecto auténtico y, al mismo tiempo, hacer visible el aprendizaje antes de la entrega final.
