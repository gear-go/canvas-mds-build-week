# Alineamiento antes de diseñar actividades

Usar esta referencia cuando Canvas MDS deba crear o revisar objetivos, indicadores, evidencias, instrumentos, procedimientos o una jornada formativa. Su función es impedir que una agenda plausible oculte una cadena evaluativa débil.

## Distinciones

- **Necesidad:** problema o brecha documentada.
- **Objetivo:** desempeño que las personas podrán demostrar al finalizar.
- **Actividad:** lo que harán para aprender o practicar.
- **Indicador:** conducta observable que permite reconocer progreso o logro.
- **Evidencia:** producto, actuación, respuesta o rastro que muestra el desempeño.
- **Instrumento:** medio para registrar o valorar la evidencia.
- **Procedimiento:** quién evalúa qué, cuándo, cómo y para qué usará el feedback.

La secuencia obligatoria es: necesidad → objetivo → indicadores → evidencia → instrumento → procedimiento → actividades.

## Objetivos

Preservar los resultados de aprendizaje aprobados como autoridad. No reescribirlos silenciosamente.

Si no existe un objetivo aprobado:

1. formular dos o tres alternativas, cada una en una sola oración;
2. separar acción observable, contenido o desempeño y condición;
3. comprobar que sea alcanzable en la duración disponible;
4. evitar *aprender*, *conocer*, *entender*, *comprender* o *familiarizarse* como acción principal;
5. excluir actividades, recursos, secuencias e instrumentos;
6. explicar diferencias y trade-offs;
7. esperar confirmación docente.

Prueba rápida: si el texto responde principalmente qué harán durante la sesión, es una actividad. Si responde qué podrán demostrar al finalizar, es un objetivo.

## Indicadores y evidencia

Derivar normalmente entre cuatro y seis indicadores. Cada indicador debe:

- usar una conducta observable;
- declarar si observa proceso o resultado;
- vincularse con uno o más objetivos;
- explicitar evidencia concreta;
- definir la condición de calidad cuando use *correctamente*, *adecuadamente* o equivalentes;
- evitar asistencia, participación o cumplimiento como único criterio.

Cubrir acción, contenido o desempeño y condición de cada objetivo. No agregar aprendizajes ausentes del objetivo.

## Selección de instrumentos

Comparar al menos tres instrumentos pertinentes antes de seleccionar. Para cada alternativa explicitar ventajas, limitaciones, alineamiento, carga de revisión, tamaño de cohorte, tiempo y capacidad de feedback.

Seleccionar exactamente un instrumento principal y solo complementos indispensables. Calcular la carga: elementos por revisar × minutos por elemento. No construir una rúbrica cuando una decisión binaria requiere una lista de cotejo.

## Procedimiento

Declarar momentos diagnósticos, de seguimiento y finales cuando sean pertinentes. Cada momento identifica actor, acción evaluativa, evidencia, instrumento, feedback y uso posterior del feedback. La evaluación entre pares o autoevaluación se incorpora solo cuando aporta al objetivo.

## Auditoría antes de calendarizar

No diseñar agenda, módulos ni actividades hasta comprobar:

1. la necesidad justifica el objetivo;
2. el objetivo no describe actividades;
3. todos sus componentes tienen indicadores;
4. cada indicador tiene evidencia;
5. cada evidencia puede valorarse con el instrumento seleccionado;
6. el procedimiento usa ese instrumento y produce feedback utilizable;
7. la carga total está calculada;
8. las actividades posteriores ejercitan exactamente esta cadena.

Registrar la matriz objetivo → indicador → evidencia → instrumento → momento evaluativo. Mantener los cambios indispensables separados de mejoras opcionales.
