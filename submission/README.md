# AssessTrace skills-only submission

This directory contains the human-readable materials for submitting **AssessTrace · Canvas MDS** as a skills-only plugin.

## Package

The upload artifact is:

`dist/assesstrace-canvas-mds-skills-only-0.1.0.zip`

The ZIP has one plugin root and contains:

- `.codex-plugin/plugin.json`
- `skills/`
- `scripts/`
- `assets/`

It intentionally excludes the repository marketplace, local configuration, Canvas credentials, reports, judge documentation, and example course profiles outside the plugin root.

## Submission type

Choose **Skills only** in the OpenAI plugin submission portal.

## Materials

- `listing.md`: proposed public listing, publisher information, starter prompts, and remaining publication blockers.
- `test-cases.md`: exactly five positive and three negative reviewer test cases.

## Remaining gates before submission

1. Verify the publisher identity that will appear publicly. Prefer a UDD-approved business identity if the university is the publisher.
2. Obtain Apps Management write permission for the submitting OpenAI Platform organization.
3. Publish and approve final website, support, privacy-policy, and terms-of-service URLs.
4. Confirm the countries or regions where support and legal terms are ready.
5. Review and approve the release notes and policy attestations in the portal.

No Canvas token, credential, student record, enrollment, submission, or grade is included in the package.
