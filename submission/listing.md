## Short description

Evidence by Design para evaluar el proceso de aprendizaje con IA.

## Long description

AssessTrace ayuda a docentes y programas a rediseñar evaluaciones para hacer visible el proceso de aprendizaje en cursos con IA. GPT-5.6 comprende la evidencia y propone alternativas; el docente confirma cada decisión material; un motor determinista valida trazabilidad, ponderaciones y barreras de seguridad; Canvas MDS inspecciona el curso y prepara únicamente estructuras no publicadas bajo confirmación explícita.

El plugin no califica, no infiere autoría, no descarga entregas ni notas, no modifica matrículas y no publica ni elimina contenido de Canvas. El rediseño excluye datos personales de estudiantes.

## Starter prompts

1. Rediseña una evaluación con Evidence by Design sin usar datos personales.
2. Audita la estructura de un curso Canvas en modo de solo lectura.
3. Prepara un dry-run para crear estructuras no publicadas en Canvas.
