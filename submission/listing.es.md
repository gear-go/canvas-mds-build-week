## Descripción breve

Evidence by Design para evaluar el proceso de aprendizaje con IA.

## Descripción extendida

AssessTrace ayuda a docentes y programas a rediseñar evaluaciones para hacer visible el proceso de aprendizaje en cursos con IA. GPT-5.6 comprende la evidencia y propone alternativas; el docente confirma cada decisión material; un motor determinista valida trazabilidad, ponderaciones y barreras de seguridad; y Canvas MDS inspecciona el curso y prepara únicamente estructuras no publicadas bajo confirmación explícita.

El plugin no califica, no infiere autoría, no descarga entregas ni calificaciones, no modifica matrículas y no publica ni elimina contenido de Canvas. El rediseño excluye datos personales de estudiantes.

## Prompts iniciales

1. Rediseña una evaluación con Evidence by Design sin usar datos personales.
2. Audita la estructura de un curso Canvas en modo de solo lectura.
3. Prepara un dry-run para crear estructuras no publicadas en Canvas.

## Notas de versión

Primer envío público de AssessTrace · Canvas MDS. El paquete incluye tres skills para configuración local segura, rediseño de evaluaciones con Evidence by Design y gestión controlada de inspección, dry-run y creación no publicada en Canvas. Incluye scripts de validación determinista y plantillas sanitizadas, sin credenciales ni registros estudiantiles.
